## 📐 Sticker Specs

### Format Info
| Property | Value |
|:---------|:------|
| **Format** | PNG |
| **Background** | Transparent ✨ |
| **Border** | Thin gray outline |
| **Resolution** | High-quality |

### 💡 Pro Tips

> **Note:** Our stickers have transparent backgrounds with a subtle gray border outline! 
> 
> If you're using them on a dark background and want better visibility, you can:
> - Add a white background fitted to the sticker shape
> - Use image editing tools to add a white/light drop shadow
> - Apply a white stroke/outline in your design software
